= Redmine SLA Plugin

== Beschreibung

Reaktionsfristen (SLA) für Redmine: Sobald eine *externe* Person ein Ticket anlegt oder kommentiert
(Weboberfläche, E-Mail über den Mail-Handler, TYPO3-Anbindung), entsteht eine Antwortpflicht mit Frist.
Eine öffentliche Antwort eines Mitarbeiters oder das Schließen des Tickets erledigt sie.

Als *intern* gelten die im Plugin +redmine_human_resources+ hinterlegten Mitarbeiter
(Anstellungsart/Eintrittsdatum gesetzt oder Zeit-/Abwesenheitsbuchungen vorhanden).
Ohne HR-Plugin gelten alle aktiven, nicht gesperrten Benutzerkonten als intern.

== Funktionen

- Administration → *SLA*: SLAs pro Projekt (Reaktionsfrist, Puffer vor Feierabend, Geschäftszeiten,
  Wochenenden/Feiertage), Feiertage (global oder je Projekt) und Sonderregeln je Tracker.
- Nur Projekte mit Projekt-SLA erhalten den Projekt-Reiter *SLA* und Antwortfristen.
- "Meine Seite"-Block *SLA – Zu beantworten* (wird beim ersten Aufruf automatisch oben eingeblendet,
  lässt sich wie jeder Block entfernen): pro Projekt eine Spalte, pro Ticket eine Ampelkarte
  (Ticket, Kommentar von / Ticket von, Zeitpunkt, Ablauf).
  Rot = überfällig, Gelb = heute fällig, Grün = im Zeitrahmen.
- Gesamtübersicht unter +/sla/dashboard+.
- Fristberechnung in Arbeitsminuten innerhalb der Geschäftszeiten (Zeitzone in den Plugin-Einstellungen).
- Beim Anlegen/Ändern eines Projekt-SLAs werden offene Fristen aus der Ticket-Historie aufgebaut.
  Manuell: +bundle exec rake redmine_sla:rebuild [PROJECT=identifier] RAILS_ENV=production+

== Voraussetzungen

- Redmine 6.x (Plugin-Assets liegen unter assets/, wie seit Redmine 6 vorgesehen)
- optional: redmine_human_resources (Mitarbeiter-Erkennung)

== Installation

    cd /path/to/redmine
    git clone https://github.com/leanderkretschmer/redmine_sla.git plugins/redmine_sla
    RAILS_ENV=production bundle exec rake redmine:plugins:migrate NAME=redmine_sla

Redmine neu starten, dann unter Administration → SLA Projekte eintragen und auf "Meine Seite"
den Block *SLA – Zu beantworten* hinzufügen.

== Deinstallation

    RAILS_ENV=production bundle exec rake redmine:plugins:migrate NAME=redmine_sla VERSION=0
    rm -rf plugins/redmine_sla
